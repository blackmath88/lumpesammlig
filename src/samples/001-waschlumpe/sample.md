# 001 — Waschlumpe

## Source object

A loosely hand-knitted washcloth with thick yarn, open holes and a lavender-grey to pale sage to mint/aqua fade.

## Observation

The useful qualities are not the photograph itself: uneven tension, changing yarn thickness, loose structure, softness, and deformation that spreads through connected fibres.

## Web translation

`KnitMaterial.tsx` is the sample-local Canvas 2D renderer. `KnitSurface.tsx` composes it as the hero, while `MaterialLab.tsx` uses the same semantic parameter model for live scale studies, a late inspection instrument and four object-specific component mutations. The pointer adds a broad, delayed tension field rather than a click ripple or magnetic attraction; idle motion stays slow and reduced-motion users receive a static render.

The mutations are staged as an exhibition rather than a gallery. Pressure gathers a control from a fabric field, a toggle spans two anchors, progress crosses a page-wide membrane, and stable content sits inside a yielding perimeter.

## Boundary

This directory belongs to Sample 001. Its rendering choices are precedent only for this object—not a template every later sample must inherit.

The public model describes openness, yarn thickness, irregularity, tension, softness, colour drift and idle motion. Quality tiers, pixel density and canvas drawing details stay private to sample 001. No cross-sample material or component framework is implied.

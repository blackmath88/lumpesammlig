# 001 — Four separate experiments, not a composite

Status: accepted, implemented 2026-10-31. Scope: this study. Retrospective reconstruction from `../sample.md` ("The study is deliberately plural: the research describes a tectonic language, not a single building, and four of its distinctions were different enough to deserve separate executable trials rather than one composite") and commit `2756f40`.

**Choice.** One page, four independent experiments (piers, façade, panels, pours), each with its own pure state model and tests, rather than a single building-like interface combining them.

**Alternatives the record names.** One composite experiment. The record does not say what it would have been; the plan document's earlier MASS / OPENING façade proposal (see `docs/AGENT-WORKBENCH-BUILD-PLAN.md` §6) is a different interpretation and must not be read as the rejected composite.

**Reasons.** The encounter is a description of a language, not an object. Each of the four behaviours (bearing, screening, arrangement, trace) has a different nearest peer in interface design and would be tested by a different interaction. A composite would make it impossible to say which behaviour carried the effect.

**Trade-offs.** The page is long and the experiments do not add up to a building; `sample.md` admits "Nothing here is a building". Four small models are easier to test than one large one, but the visitor meets four separate arguments rather than one experience.

**Grounding.** Report 02 §4 feature table, which already separates the devices; `docs/CONCEPT.md` §7 ("several competing prototypes" is a legitimate form).

**Revisit if.** A later reflection finds that two of the four are the same behaviour in different clothes, or if human review finds the plurality reads as a catalogue rather than a study.
